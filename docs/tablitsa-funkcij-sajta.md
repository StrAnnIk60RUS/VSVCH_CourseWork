# Таблица функций веб-приложения VSVH Languages

Документ описывает реализованные пользовательские функции платформы для изучения языков (роли: гость, студент, преподаватель). Формат соответствует пояснительной записке: **функция — описание — web-страница**.

---

| Функция | Описание функции | Web-страница |
|---------|------------------|--------------|
| Персонализация темы | Пользователь может переключаться между светлой и тёмной темой через меню «Настройки» в шапке сайта. Выбранная тема сохраняется в `localStorage` и применяется ко всем страницам. | Все страницы |
| Локализация интерфейса | Пользователь может переключать язык интерфейса (русский / английский) в меню «Настройки». Язык сохраняется в `localStorage` и влияет на подписи элементов UI. | Все страницы |
| Поиск курсов | Пользователь может вводить ключевые слова для поиска курсов по названию и описанию. Результаты отображаются в виде карточек с названием, описанием, языком, уровнем, числом уроков и средним рейтингом. | Каталог курсов |
| Фильтрация каталога | Пользователь может ограничить список курсов по языку обучения, уровню сложности (A1–C2) и минимальному среднему рейтингу. Параметры фильтра сохраняются в `localStorage`. | Каталог курсов |
| Сортировка каталога | Пользователь может отсортировать курсы по дате создания (сначала новые или старые), по рейтингу (от большего к меньшему) и по популярности (числу записей на курс). | Каталог курсов |
| Пагинация каталога | Список курсов разбит на страницы (по 8 курсов). Пользователь переключает страницы кнопками «Назад» / «Вперёд»; номер страницы сохраняется в `localStorage`. | Каталог курсов |
| Рекомендуемые курсы на главной | На главной странице для гостей и студентов отображаются популярные курсы (топ по числу записей) и быстрые ссылки на предустановленные фильтры каталога. | Главная страница |
| Регистрация и авторизация | Гость может зарегистрироваться (имя, e-mail, пароль, роль «студент» или «преподаватель») или войти в систему. После успешного входа JWT сохраняется в `localStorage`, открывается доступ к личным разделам. | Вход, Регистрация |
| Просмотр карточки курса | Пользователь видит описание курса, язык, уровень, средний рейтинг, список уроков с индикатором прогресса по каждому уроку (для авторизованного студента) и ссылки на прохождение уроков. | Карточка курса |
| Запись на курс и отписка | Студент может записаться на курс или отписаться с карточки курса. Состояние записи отображается кнопкой «Записаться» / «Отписаться». | Карточка курса |
| Избранные курсы | Студент может добавить курс в избранное или удалить его на карточке курса. Список избранного доступен на отдельной странице с переходом к курсу и удалением из списка. | Карточка курса, Избранное |
| Система отзывов и рейтингов | На основе оценок (1–5) и комментариев студентов автоматически рассчитывается средний рейтинг курса. Студент может оставить или изменить свой отзыв только после записи на курс. Рейтинг отображается в каталоге, на карточке курса и на странице всех отзывов. | Карточка курса, Отзывы курса, Каталог курсов |
| Прохождение уроков | Авторизованный пользователь открывает урок: отображаются текст материала, навигация по урокам курса и переход к следующему уроку. Студент с активной записью получает доступ к упражнениям. | Страница урока |
| Выполнение упражнений | Студент, записанный на курс, вводит ответы на упражнения урока и отправляет их на проверку. Система показывает результат (верно/неверно, балл), сохраняет лучшую попытку и пересчитывает прогресс по курсу и уроку. | Страница урока |
| Моё обучение | Студент видит список записанных курсов с процентом прогресса, переходит к курсу, отписывается от курса. При достижении 100% прогресса доступна выдача сертификата и скачивание PDF. | Моё обучение |
| История активности студента | Студент просматривает хронологический список своих отправок ответов на упражнения (название упражнения, балл, дата). | Прогресс |
| Управление данными (CRUD) — преподаватель | Преподаватель может создавать, редактировать и удалять свои курсы (название, описание, язык, уровень), уроки (заголовок, содержание, порядок) и упражнения (вопрос, максимальный балл). Управление выполняется в кабинете курса. | Курсы преподавателя, Создание курса, Управление курсом |
| Управление студентами курса | Преподаватель видит таблицу записавшихся студентов (имя, e-mail, прогресс %, активность). Доступны фильтр по статусу (активные / неактивные) и сортировка по имени, прогрессу или последней активности. | Управление курсом |
| Аналитика по курсу | Преподаватель выбирает курс и период (7 / 30 / 90 дней), просматривает KPI (число студентов, средний прогресс, активные за 7 дней, «группа риска»), график отправок и активности, распределение прогресса по диапазонам, прогресс отдельных студентов с фильтром «только группа риска». | Аналитика |
| Напоминания | Авторизованный пользователь создаёт, редактирует и удаляет напоминания (заголовок, дата и время срабатывания). Список отсортирован по времени напоминания. | Напоминания |
| Уведомления о напоминаниях | При наступлении времени напоминания приложение опрашивает сервер (каждые 30 с) и показывает всплывающее уведомление в правом верхнем углу с названием и временем. Пользователь может закрыть уведомление (напоминание удаляется). | Все страницы |
| Формирование отчётов (студент) | Студент скачивает отчёт о своём прогрессе в форматах PDF и DOCX или запрашивает отправку отчёта на e-mail (при настроенном SMTP на сервере, иначе демо-режим). | Прогресс |
| Формирование отчётов (преподаватель) | Преподаватель скачивает сводный отчёт по курсу (PDF, DOCX), экспортирует список студентов в CSV и отправляет отчёт на e-mail со страниц управления курсом и аналитики. | Управление курсом, Аналитика |
| Профиль пользователя | Авторизованный пользователь просматривает e-mail, изменяет отображаемое имя и сбрасывает сохранённые настройки интерфейса (тема, язык, фильтры каталога, сортировка, страница каталога). Выход из системы выполняется из шапки сайта. | Профиль |

## Соответствие маршрутов и названий страниц

| Название в таблице | Маршрут |
|--------------------|---------|
| Главная страница | `/` |

| Регистрация | `/register` |
| Каталог курсов | `/courses` |
| Карточка курса | `/courses/:courseId` |
| Отзывы курса | `/courses/:courseId/reviews` |
| Страница урока | `/courses/:courseId/lessons/:lessonId` |
| Моё обучение | `/me/learning` |
| Избранное | `/me/favorites` |
| Прогресс | `/me/progress` |
| Напоминания | `/me/reminders` |
| Профиль | `/me/profile` |
| Курсы преподавателя | `/teacher/courses` |
| Создание курса | `/teacher/courses/new` |
| Управление курсом | `/teacher/courses/:courseId` |
| Аналитика | `/teacher/analytics` |
| Все страницы | Любой маршрут приложения |
